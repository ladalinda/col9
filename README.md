# Сайт «Колумбия с ICETEX»

Статический сайт на русском без сборки и без зависимостей: обычные HTML, CSS и JS. Работает на GitHub Pages.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на github.com (например `colombia`), загрузите в него **всё содержимое этой папки** (включая скрытый файл `.nojekyll`).
2. Откройте Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту-две сайт откроется по адресу `https://ВАШ_НИК.github.io/colombia/`.
4. Свой домен (по желанию): в том же разделе впишите домен и добавьте файл `CNAME` с этим доменом.

Все ссылки на сайте относительные, поэтому он работает и по адресу с названием репозитория, и на своём домене.

## Что заполнить (ищите жёлтые пометки `[...]` на страницах)
- **`assets/js/config.js`**: email, Telegram, Instagram, ссылки на официальный каталог и инфографику, дата проверки правил. Пока поля пустые, ссылки неактивны.
- **Фото:** положите файл `assets/img/lada.jpg` (лучше вертикальное, 4:5).
- **Адрес сайта:** в `sitemap.xml` и `robots.txt` замените `https://USERNAME.github.io/REPO` на ваш.
- **404.html:** если сайт лежит по адресу с названием репозитория, замените `<base href="/">` на `<base href="/colombia/">`.

## Ссылки для Instagram
Каждый раздел это отдельная страница, поэтому в видео и ответах на ключевые слова можно давать прямые ссылки. `UTM`-метки сохраняются в заявках, чтобы вы видели, откуда пришёл человек.

| Ключевое слово | Ссылка |
| --- | --- |
| КОЛУМБИЯ | `/?utm_source=instagram&utm_campaign=kolumbiya` |
| ТЕСТ | `/test/?utm_source=instagram&utm_campaign=test` |
| БАЛЛЫ | `/baly/?utm_source=instagram&utm_campaign=baly` |
| ГОРОДА | `/goroda/?utm_source=instagram&utm_campaign=goroda` |
| СРОКИ | `/sroki/?utm_source=instagram&utm_campaign=sroki` |
| БЮДЖЕТ | `/byudzhet/?utm_source=instagram&utm_campaign=byudzhet` |

Перед ссылкой допишите адрес сайта. Другие страницы: `/varianty/`, `/usloviya/`, `/plan/`, `/dokumenty/`, `/katalog/`, `/ispanskij/`, `/uslugi/`, `/voprosy/`, `/obo-mne/`, `/slovar/`.

## Структура
```
index.html            главная
varianty/ goroda/ sroki/ test/ baly/ usloviya/ plan/ dokumenty/ katalog/
ispanskij/ byudzhet/ uslugi/ voprosy/ obo-mne/ slovar/
404.html  sitemap.xml  robots.txt  .nojekyll
assets/css/style.css  assets/js/main.js  assets/js/config.js  assets/img/
```
Цвета и шрифты меняются в начале `assets/css/style.css` (блок `:root`). Плашка про набор 2027 и подвал одинаковы на всех страницах; чтобы изменить их, замените текст во всех файлах `index.html` (поиск по фразе «Следующий набор»).

## Важно
Правила на сайте взяты из call 2026-2. Когда выйдет новый call, обновите даты и цифры и поменяйте дату проверки в `config.js`.
